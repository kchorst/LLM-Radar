# LLM Radar 0.7.0 User Guide

## Overview
LLM Radar is a phone-first local AI proof tool[cite: 1]. It connects your mobile device to a Local AI server running on a computer over the same Wi-Fi or LAN[cite: 1]. The AI model runs entirely on the computer, not on your phone[cite: 1]. 

## Quick Start Guide
1. Start Local AI on your computer[cite: 1]. 
2. Double-click `Start_Here.bat`[cite: 1]. 
3. Leave the trusted command-window heartbeat open while using LLM Radar[cite: 1, 3]. Note that there is no Windows GUI in this release[cite: 1, 3].
4. On your phone, scan the generated QR code[cite: 1].
5. Open the **Chat** tab at the bottom of the mobile interface[cite: 1, 3].
6. Locate the **Enter chat here** placeholder and send one short message to verify the connection[cite: 1, 3].
7. Open **Files** and try the **Sample** option[cite: 1].

## File Uploads
* You can upload clean TXT or MD files[cite: 1, 3]. 
* A readable-text gate will automatically reject files containing obvious gibberish or repeated-token text[cite: 1, 3].

## Troubleshooting & Recovery
* Do not start over from scratch if you encounter an issue; use **Check Again** or **Reconnect QR** on your phone instead[cite: 1].
* If Chat works but the Sample text transfer fails, your Files screen will display **QR refresh needed**[cite: 3]. Tap **Reconnect QR**, scan the code again, and retry the Sample[cite: 1, 3].
* If Windows firewall or Wi-Fi isolation blocks the computer file route, the app will point you to Rescan QR, Try Sample, or Diagnostics[cite: 2].
* Always use **Refresh Status** on the browser page after starting or restarting your Local AI[cite: 1, 3].

## Known Limitations
* Android keyboard behavior still requires real-device acceptance testing[cite: 2].
* While loading a Sample only requires the computer file route, Local AI must be running for model summary/ask functionality[cite: 2].
